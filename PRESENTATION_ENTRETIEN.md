# PRÉSENTATION DE MINACHAT

## INTRODUCTION (30 secondes)
"Bonjour, je vous présente **Minachat**, une application de messagerie en temps réel que j'ai développée dans le cadre de mon BTS SIO SLAM. C'est une plateforme moderne de communication privée avec un système d'administration complet."

## ARCHITECTURE TECHNIQUE (1 minute)
"Minachat utilise une **stack technique moderne et robuste** :

**Backend :**
- Node.js avec Express pour l'API REST
- PostgreSQL comme base de données relationnelle
- Authentification sécurisée avec JWT et bcrypt
- Socket.io pour le temps réel

**Frontend :**
- React 19 avec Vite pour le développement rapide
- Tailwind CSS pour un design moderne et responsive
- React Router pour la navigation
- Framer Motion pour les animations fluides

L'architecture suit les bonnes pratiques avec une séparation claire entre backend et frontend."

## FONCTIONNALITÉS PRINCIPALES (1 minute)
"Le projet comprend plusieurs fonctionnalités clés :

**🔐 Système d'authentification :**
- Inscription avec validation obligatoire par un administrateur
- Gestion des rôles utilisateur et administrateur
- Profils enrichis avec avatar et biographie

**👑 Panneau d'administration :**
- Validation des nouvelles inscriptions en attente
- Gestion complète des utilisateurs : bloquer, avertir, supprimer
- Création de comptes directement depuis l'interface
- Système d'avertissements avec compteur automatique

**💬 Messagerie privée :**
- Chat en temps réel entre utilisateurs validés
- Interface intuitive avec historique des conversations
- Rafraîchissement automatique des messages"

## DÉMONSTRATION (1 minute)
"Je vais maintenant vous montrer l'application en fonctionnement :

1. **Page d'accueil** : Redirection automatique vers la page de connexion
2. **Inscription** : Formulaire complet avec avatar et description
3. **Validation admin** : Processus d'approbation des comptes
4. **Interface de chat** : Messagerie moderne et fluide
5. **Panneau admin** : Gestion complète des utilisateurs"

## QUALITÉS TECHNIQUES (30 secondes)
"Ce projet démontre plusieurs compétences techniques :

- **Architecture propre** : Séparation claire des responsabilités
- **Sécurité** : Hash des mots de passe, tokens JWT, validation des données
- **Base de données** : Schéma relationnel optimisé avec PostgreSQL
- **Interface utilisateur** : Design responsive et moderne
- **Tests** : Configuration Jest pour les tests unitaires
- **Déploiement** : Scripts d'installation et de configuration"

## PERSPECTIVES D'ÉVOLUTION (30 secondes)
"Le projet est évolutif et pourrait être étendu avec :

- Migration complète vers WebSocket pour de meilleures performances
- Chat de groupe et canaux de discussion
- Envoi de fichiers et médias
- Notifications push et authentification 2FA
- Déploiement en production avec Docker et CI/CD"

## CONCLUSION (15 secondes)
"Minachat représente un projet complet qui démontre mes compétences en développement full-stack, de la conception à la mise en production. Il intègre les bonnes pratiques de sécurité et d'architecture logicielle."
